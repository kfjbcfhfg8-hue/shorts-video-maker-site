Shorts Video Maker

最終更新日：2026年11月23日

Shorts Video Maker（以下「本アプリ」）は、 YouTube Shorts向け動画の制作と アップロードを支援する個人開発ツールです。 本ポリシーでは、利用する情報と その取り扱いについて説明します。

1. 取得・利用する情報

本アプリは、利用者がGoogleアカウントで アクセスを許可した場合、 YouTubeへの動画アップロードに必要な OAuth認証情報を利用します。

また、アップロードする動画、 タイトル、説明文などの情報を扱います。

2. 利用目的

取得した認証情報は、利用者が許可した YouTubeチャンネルへの動画アップロードと、 その認証を維持する目的で使用します。

動画の作成、アップロード、 投稿済み台本の記録にも情報を利用します。

3. 情報の保存と管理

OAuth認証情報はGitHub Actionsの Secrets機能を利用して管理します。 認証情報を公開リポジトリや 公開ホームページには掲載しません。

動画ファイルや投稿履歴は、 動画生成・投稿の管理に必要な範囲で GitHubの関連機能に保存されます。

4. 外部サービスへの情報送信

本アプリは、動画アップロードのために GoogleのYouTube Data APIを利用します。 また、処理の実行や情報の管理のために GitHubのサービスを利用します。

これらのサービスでは、それぞれの プライバシーポリシーも適用されます。

  • Google プライバシーポリシー
  • GitHub プライバシーステートメント

5. Googleユーザーデータの取り扱い

Google APIから取得したユーザーデータは、 アプリの明示された機能を提供するために 必要な範囲でのみ利用します。

広告配信を目的とした利用や、 ユーザーデータの販売は行いません。

Google APIサービスから取得した情報の 利用については、適用される Google API Services User Data Policyに 従って取り扱います。

Google API Services User Data Policy

6. アクセス権限の取り消し

利用者は、Googleアカウントの 接続済みアプリの管理画面から、 本アプリへのアクセス許可を 取り消すことができます。

Googleアカウントの接続管理

7. 情報の削除

本アプリの管理者は、管理する認証情報や 投稿管理データについて、 必要がなくなった場合に削除します。

情報の削除について確認が必要な場合は、 下記のお問い合わせ先からご連絡ください。 Googleでのアクセス許可の取り消しと、 保存済みデータの削除は別の操作です。

8. ポリシーの変更

本ポリシーは、アプリの機能変更や 関連する規約の変更に応じて 更新される場合があります。 更新内容は本ページに掲載します。
